# Z-Envio Installer

Repositório oficial para distribuição do instalador do Z-Envio para Windows.

## Sobre

O **Z-Envio** é uma solução desenvolvida para facilitar o envio de pedidos, integração com plataformas e automação de processos logísticos.

Este repositório mantém as versões do instalador `.exe` para Windows.

## Instalação

1. Acesse a seção de [Releases](https://github.com/seu-usuario/z-envio-installer/releases).
2. Baixe a versão mais recente do arquivo `.exe`.
3. Execute o instalador e siga as instruções na tela.

## Atualizações

- Sempre verifique a última versão disponível nas releases.
- Para ver o histórico de mudanças, consulte o [CHANGELOG.md](CHANGELOG.md).
